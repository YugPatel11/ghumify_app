# Third-Party Data & Map Attributions

This document records the mandatory data licensing and attribution requirements for external providers used in the Ghumify backend:

### 1. OpenStreetMap (OSM)
- **Attribution**: "© OpenStreetMap contributors"
- **License**: Open Database License (ODbL) 1.0 (https://opendatacommons.org/licenses/odbl/)
- **Usage Etiquette**: Requests routed via Overpass API include descriptive `User-Agent: Ghumify-Backend/1.0 (travel-planner; contact@ghumify.app)` with local caching and concurrency throttling.

### 2. Geoapify
- **Attribution**: "Powered by Geoapify" (https://www.geoapify.com/)
- **Usage**: Places and Geocoding APIs utilized within standard free tier limits with local cache persistence.

### 3. Google Maps Platform
- **Attribution**: Google Places and Distance Matrix APIs (https://cloud.google.com/maps-platform/terms)
